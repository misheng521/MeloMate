# 聊天、记忆和工作如何连在一起

MeloMate 把当前人设、记忆、真实程序状态和工具结果提供给同一个聊天模型。它能据此延续对话、了解变化、决定是否检查资料或回应。没有另设人格控制器，也没有关系阶段、好感分数或必须越来越亲密的目标。

人设描述角色已有的背景与倾向，具体表现结合情境决定，不要求每轮展示或印证这些特征。记忆保留具体经历，不把一次表现写成永久性格；详见 [人设的使用方式](MEMORY.md#人设是背景与倾向)。

## 使用起来有什么变化

| 你做的事 | 程序怎样处理 |
|---|---|
| 正常文字或语音聊天 | 每轮读取当前人设、记忆和会话状态，交给同一个模型回答 |
| 不关闭应用，编辑并保存 `memory.md` | 检测内容变化，下一轮使用新记忆，同时告诉模型发生过外部编辑；不会猜测是谁改的、为什么改 |
| 编辑人设正文 | 后续轮次读取新正文，并提供人设变化通知；程序不自动修改人设 |
| 打开主动说话 | 除原有定时机会外，记忆或人设变化也可提供一次回应机会；模型可以说话，也可以沉默 |
| 关闭主动说话 | 文件仍会读取和更新本地状态，变化本身不会发起模型请求；等你下次聊天时提供给模型 |
| 让它完成工作 | 当前项目、模型保存的计划、近期工具成功或失败、上一轮是否中断一起提供给模型，帮助它判断下一步 |

文字聊天也可以主动说话，不需要先打开麦克风。前提是页面与后端已经连接。关闭开关不会撤回已经发给 API 的请求；需要停止正在生成的回复时使用现有停止操作。

页面通常每 5 秒做一次**本地检查**，检查本身不请求模型。浏览器进入后台、计算机休眠或断线时可能延迟。模型正在回复、你正在说话或输入优先状态生效时，不抢着启动事件回应。多次快速修改会合并到后续机会；文件变化引起的请求至少间隔 60 秒。原有定时主动说话仍按界面设置运行。

事件回应使用原来的聊天、字幕、语音和工具流程。模型选择沉默时，内部静默标记不会显示、播报或存成一句话，也不算作你没有回应。真正说出的内容进入聊天档案；程序事件不假扮用户发言。即使选择沉默，这次模型判断也有 API 用量。

## 用户仍只需要两份角色文本

- `characters/profiles/角色名.md`：名字与用户提供的人设。
- `characters/memory/<角色ID>/memory.md`：值得保留的经历与事实，可以手动修改。

没有新增需要用户维护的情绪表、关系表、自我认知文件或事件文件。详细路径、角色创建、旧数据迁移和记忆删改规则见 [人设与记忆说明](MEMORY.md)。API、语音、项目和服务连接仍通过已有运行设置配置，工具统一允许调用。

变化记录和已处理位置存入现有 `.history.sqlite3`，只保存变化类型、序号和发现时间，不把被删记忆或旧人设正文复制进通知。保留最近 16 条变化，可跨重启处理尚未完成的通知；失败或中断不会直接标记为已经处理。格式整理或调整记忆条目顺序通常不会产生内容变化通知。

当前连接、最近工具状态和上一轮结果属于本次会话状态，重连后重新建立。聊天档案、记忆与已有任务计划按原来的方式保存在本地。它们有助于继续工作，但不代表程序关闭后模型仍一直思考、观察或执行。

## 模型知道什么

模型会得到一段简短的软件说明，以及当前时间、角色、连接期间的输入开关、项目、计划、近期工具结果和待处理变化。新增只读工具 `get_session_state`，使它可以在一轮对话中重新检查这些状态。

麦克风或屏幕开关只表示通道状态，不表示模型已经听见声音或看见画面。计划是模型记录的待办与进度，不是独立完成证明。调用工具成功也仍需根据结果判断实际任务是否完成。

文件变化引起的自动回应只提供会话、记忆、计划、能力等只读工具，不因文件变化自行执行修改或外部操作。这是自动回应的调用范围，与工具许可选项无关；正常用户对话中的已接入工具统一允许，仍受当前项目与服务范围限制。

不把整个源码塞进每轮请求。源码文件不等于经历，完整加载也不能让模型始终记住所有实现细节。这次连接的是对话实际需要的状态和经历，不训练模型权重，不保证真人般的感受或记忆准确度。

## 实现与验证

- `companion_session.py`：组织同一角色的运行状态、变化通知与回应机会。
- `chat_history_manager.py`：本地检测记忆及人设版本，持久化简短变化记录。
- `service_context.py`、`single_conversation.py`：每轮传递状态，将工具结果和回应结果接回同一会话。
- `websocket_handler.py`、`src/main.ts`：本地检查、开关、忙碌检查、事件验证及正常聊天入口。
- `pc_tools.py`：提供 `get_session_state`，检查当前会话与调用范围。

源码回归命令（使用已经准备好的 Python、Node 与项目依赖）：

```text
python -B -m unittest discover -s backend/tests -p test_companion_session.py
python -B -m unittest discover -s backend/tests -p test_pc_work_tools.py
python -B -m unittest discover -s backend/tests -p test_text_memory.py
npm run test:session
npm run test:security
npm run check
npm run build
```

测试覆盖实际本地存储、事件验证、工具执行循环及前端函数；模型、语音和浏览器界面使用替身。未调用真实聊天 API，也未完成完整语音或真实模型端到端验证。自然程度还需要用实际接入的模型聊天检验。
