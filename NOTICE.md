# Notice

This source tree contains third-party runtime assets and SDK code.

- `three` and `@pixiv/three-vrm` provide local VRM rendering under their respective open-source licenses.
- VRM files placed in `models/` keep their own author and redistribution terms. Inspect each model's embedded VRM metadata before sharing it.
- `public/libs` contains browser runtime libraries and WASM files used for local audio/VAD features.

Do not publish a public release until you have confirmed that every bundled model, audio sample, SDK file, and library can be redistributed under the release terms you choose.
